## ✦ 概览

《神秘学手册》（**Occodex**）是一部融合东方正统术数（命、卜）与西方赫尔密斯星历传统的交互式研习典籍。全站采用纯原生 Web 前端工程构建（HTML5 / ES6+ / SVG / CSS3 / Web Audio API），零打包工具、零重型框架、零服务端数据库依赖，具备极高的本地独立运行与长久保真归档能力。

## ✦ 运行与部署

### 本地直接运行
双击打开 `index.html` 或通过本地 HTTP 服务器运行：
```bash
python -m http.server 8399
# 打开浏览器访问 http://127.0.0.1:8399/index.html
```

### 部署到 Cloudflare Pages（推荐）
1. 登录 Cloudflare Dashboard -> **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
2. 关联本仓库 `V2tin19/occodex`。
3. 构建预设选择 `None`，输出目录填 `.`，点击 **Save and Deploy** 即可实现全球 CDN 极速分发与秒开体验。

### 自动化验证与质量门禁
```bash
python tools/check.py
```
（包含全站 HTML 脚本语法校验、lib 库断盘回归测试、顶层作用域扫描与本地连通性验证）
